📌 Project Overview
For this project, I was hired to help a client analyze the Manhattan vacation rental market. The goal was to provide guidance on which property types to invest in by uncovering key insights from Airbnb data.

My analysis focused on answering two major questions:
Which neighborhoods and property sizes (i.e., number of bedrooms) are most attractive for vacation rentals?
How much money did these listings generate?

🔎 Approach & Methodology

1. Defining Attractiveness
To assess a listing’s attractiveness, I used the number_of_reviews_ltm column. Since reviews are typically left after a stay, they serve as a strong indicator of how often a property is rented.

2. Data Cleaning
Before building pivot tables, I made sure the data was consistent and accurate:
Cleaned the neighborhood column to fix inconsistent capitalization and remove trailing spaces.
Stored cleaned values in a new column called neighborhood_clean.
Created a copy of the raw dataset and documented all cleaning steps in a separate sheet for transparency.

3. Pivot Table Analysis
To answer the research questions, I built pivot tables to analyze:
The neighborhoods most attractive for vacation rentals.
The property sizes (number of bedrooms) that are most popular.
Whether different neighborhoods have different preferences for property sizes.

📊 Key Questions Answered
Which 10 neighborhoods are most attractive for vacation rentals?
Which property sizes perform best across neighborhoods?
How much revenue was generated by these listings?

💡 Insights & Recommendations
Based on my pivot table analysis, I was able to identify the top-performing neighborhoods and property types that generate the most engagement and income. These insights can guide strategic investment decisions for short-term rental properties in Manhattan.
