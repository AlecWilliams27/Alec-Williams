## 📌 Featured Projects  

- 🛒 **Shopify App Analysis (Power BI)**  
  [View Dashboard](#)  
  Reviewed the Shopify App Store landscape using **shopify.xlsx** (apps, app_categories, categories, reviews) to identify what drives app success.  
  **Project Scope:**  
  - App landscape: unique app count (KPI), review volume over time, rating vs. reviews scatter.  
  - Reviews: DAX features like `helpful_reviews = rating * (1 + helpful_count)` and `developer_answered`.  
  - App–Reviews modeling: many-to-one relationship on `app_id` → `id`; analyzed developer performance by **average helpful_reviews** and responsiveness.  
  **Results Highlight:** Found categories with strong **rating–volume balance** and showed that **developer responsiveness** correlates with higher average ratings.  

- 🍴 **Zomato Dashboard Final Project (Power BI)**  
  [View Dashboard](https://app.powerbi.com/view?r=eyJrIjoiM2Y2Zjc3ZWUtNjBkYi00NDFjLTk5Y2QtMTdjYWE1OTEzMWUwIiwidCI6IjhmYmUxMWMzLTY4YjUtNDc2MC1hYjgyLWJhMzU2MjAzMzdiZiIsImMiOjJ9&embedImagePlaceholder=true)  
  A capstone-style sprint project focused on analyzing the Zomato dataset to uncover restaurant performance insights. The project was completed in two main phases: **decomposition (planning)** and **dashboard + conclusions (execution)**.  
  **Project Scope:**  
  - **Decomposition:** Built a structured research plan identifying key metrics, hypotheses, and visualizations to explore customer behavior, cuisine trends, and sales performance.  
  - **Dashboard:** Developed a Power BI dashboard that tells a story—each visualization connected to findings on restaurant categories, customer ratings, and revenue drivers.  
  - **Report & Recommendations:** Delivered a written analysis summarizing insights and offering business recommendations to improve restaurant performance.  
  **Assessment Criteria:**  
  - Research plan (clear hypotheses + metrics aligned to business goals).  
  - Dashboard relevance (visuals tied to insights, coherent story arc).  
  - Report (conclusions + actionable recommendations).  
  **Results Highlight:** The dashboard revealed that **certain cuisines consistently drove high sales**, while others with poor ratings and high return patterns needed to be phased out, leading to clear strategies for growth and cost control.  

- 🏠 **Airbnb Manhattan Market Analysis (Spreadsheet)**  
  [View Project Spreadsheet](https://docs.google.com/spreadsheets/d/1EFW-9JcKppfMliRt_biVELzRMBYgRr7myyPswshzsns/edit?usp=sharing)  
  Hired by a client to analyze the **Manhattan vacation rental market** and recommend which property types to invest in.  
  **Key Questions Answered:**  
  - Which neighborhoods and property sizes (bedroom counts) are most attractive for vacation rentals?  
  - How much revenue do these listings generate?  
  **Results Highlight:** Certain neighborhoods with **2–3 bedroom properties consistently generated the highest rental frequency and revenue.**  

- 🛍️ **E-commerce Event Log Analysis (Google Sheets)**  
  [View Project Spreadsheet](https://docs.google.com/spreadsheets/d/1_D7ZXX-UjYCxaPAAZYiixekJoIIuVWbZ2YC3sTchano/edit?pli=1&gid=38637670#gid=38637670)

  **Project Scope:**  
  - Explored raw user activity (product views, cart opens, purchases) from the `raw_user_activity` tab.

- 📖 **Storytelling with Data: Returns Analysis Dashboard (Tableau)**  
  [View Dashboard](https://public.tableau.com/app/profile/alec.williams2101/viz/SuperstorePowerpointPresentation/ReturnRateStory?publish=yes)  
  **Files Used:** Superstore.xls  
  Prepared an executive-level analysis for the CEO of the Superstore to understand **why orders were being returned** and how to reduce them.  
  **Project Scope:**  
  - Built worksheets analyzing return rates across product subcategories, customer segments, geographies, and time.  
  - Designed a dashboard to monitor returns with multiple visualization types (scatterplots, bar charts, maps, composite charts).  
  - Developed a **story arc presentation** to communicate findings and guide decision-making.  
  **Results Highlight:** Identified categories and customer segments with **disproportionately high return rates** and provided clear recommendations to reduce return volume and associated costs.  

- 📊 **Data Visualization Project: Saving SuperStore (Tableau)**  
  [View Tableau Dashboard](https://public.tableau.com/app/profile/alec.williams2101/viz/DataVisualizationProjectComplete/SuperStoreDashboard)  
  The superstore was at risk of bankruptcy — I was hired to analyze operations and improve profitability.  
  **Project Scope:**  
  - Identified top profit centers and biggest loss-makers using subcategories, regions, and shipping modes.  
  - Evaluated advertising ROI by state and month, recommending where to focus spend.  
  - Analyzed returns data to find products/customers with abnormal return rates.  
  **Results Highlight:** Delivered clear recommendations on which products to cut, where to advertise, and how to minimize losses from returns.
